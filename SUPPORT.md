# Support and contact

## Public support

Search the [documentation](specs/00-overview.md)
and existing [issues](https://github.com/nikomatt69/cadcamfun/issues) first. Use
the bug or feature-request template for a new report. Include the app version or
commit, operating system, steps, expected result and actual result. Use a minimal
synthetic model and redact logs before sharing them.

Never include API keys, OAuth grants, signing keys, pairing links, local database
files, personal information or proprietary customer drawings. Public issue
history may remain in caches and forks even after a comment is edited.

## Private contact

Maintainer and licensing contact: **Nicola Mattioli**,
[@nikomatt69 on X](https://x.com/nikomatt69).

Use a direct message for licensing, privacy, conduct and other confidential
inquiries. If messages are unavailable, ask for a private channel without
revealing confidential details. Agree a suitable secure transfer method before
sending credentials, personal records or sensitive documents. X processes
communications under its own terms; this contact is not a promise of encrypted
delivery, identity verification or a particular response time.

Security issues must follow [SECURITY.md](SECURITY.md).

## Scope and availability

Community support is best effort. Opening an issue does not create a support
contract, service-level agreement, deadline or entitlement to proprietary code.
Commercial support, deployment assistance and proprietary use require a separate
written agreement. Third-party model billing and account questions belong with
the relevant provider.

The software is an engineering aid. Community answers are not machine-specific
approval, safety certification or a substitute for a qualified operator. See
[TERMS.md](TERMS.md) and the applicable component licenses.
