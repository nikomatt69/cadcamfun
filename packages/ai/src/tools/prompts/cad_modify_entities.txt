Change fields of elements that already exist, by id.

Use it
- Resize, move, recolour, rename or move to another layer something you or the user created.

Do not use it
- To create elements (cad_add_elements / cad_add_entities) or to remove them (cad_delete_entities).
- With an id you have not read: get ids from cad_describe_drawing or from an add result.

Parameters
- changes: 1 or more {id, changes}. changes may hold any of: center {x,y,z?}, start, end, origin (rectangles: the corner), radius, startAngle, endAngle, width, height, depth, tube (torus), points, closed, name, color, layer; and any other field of the element in its own shape (the one cad_add_elements takes): x, y, z, rotation {x,y,z} in DEGREES, scale, wireframe, opacity, segments, radiusX, length, thickness, profile, path, operands, history... Only the fields you give change; an array or object field is replaced whole.
- For named dimensions of a parametric part, prefer cad_parametric inspect/update with expectedRevision. Here {"parameters":{"width":80}} also keeps the features; send history only to change features, as an object with the same schema cad_parametric validates.
- The result is refused (nothing changes) when the change would leave an element the editor cannot draw, for example a parametric history that builds no solid; the error says why.
- Millimetres, radians. radius, width, height, depth, tube must be > 0.

Result (JSON)
- ok, modified (count), elements (the updated elements), projectId, drawingId.
- If any id is unknown nothing is changed and the result is {ok:false, error:"Unknown element ids: ..."}: list the drawing again.

Example
- Make wheel "w1" bigger and move it: {"changes":[{"id":"w1","changes":{"radius":35,"center":{"x":-120,"y":60,"z":35}}}]}
- Turn a bracket "b1" upright and make a parametric plate "p1" 10 mm wider: {"changes":[{"id":"b1","changes":{"rotation":{"x":90,"y":0,"z":0}}},{"id":"p1","changes":{"parameters":{"width":70}}}]}
