Save project notes and standing context so the next conversation starts where this one stopped.
Call with action and its fields. Read the current note/section before replacing it; other sessions share this project's memory.

Actions
- remember: store one note under a stable key; writing the key again replaces it.
- context_update: replace or add one section (by its heading) of the project's standing context document.

Parameters
- remember: key (letters, digits, dot, dash, underscore; up to 80 characters), value (up to 2000).
- context_update: heading (the section's name, up to 80), content (the section's body, up to 2000).

Result (JSON)
- ok, key; context_update returns the document the store actually kept, plus changed: true. If it did not keep it, ok:false says so.

Do not use it
- To read them first: memory.
- Keep confirmed reusable facts, units, source and relevant drawing/setup identity. Do not store secrets, transient revisions, speculative geometry, failed operations, private reasoning or transcripts. Session progress belongs in the native plan/goal, not shared project rules.
- The standing context changes every later conversation in this project: write only what the user confirmed.
