Inspect real stored element properties and the current editor's layers, with explicit pagination. Do not use it to guess omitted geometry or modify the document.

Parameters
- action: elements | layers | property.
- ids: optional filter by existing element ids (at most 20); layerId: optional layer filter.
- offset: nonnegative page index (elements) or character offset (property), default 0.
- limit: elements per page (1 to 20, default 10).
- elementId: target element for property reading; path: array of object keys or child-array indices (e.g. ["history","parameters"]); maxChars: property JSON characters, 1 to 20000.

Result
Elements include actual properties (geometry, transforms, history, visibility, layer and nested children), bounds, total and nextOffset. Large values are marked omitted with a readWith property request, never silently discarded. layers returns live layer properties with snapshot timestamp/source or explicit unavailable state. property returns exact paginated JSON text and nextOffset. Layer snapshot is editor evidence, not a geometry mutation. Read every required page before claiming a complete inspection.
