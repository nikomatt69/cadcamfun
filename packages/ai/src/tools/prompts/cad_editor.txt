Drive the open editor itself: create, rename, recolour, show, hide, lock and delete layers, switch the view between 3D and 2D and fit it, cut the model open with a section plane at one point along an axis (section_on / section_off), select elements, hide, show or isolate them, and undo or redo. The elements themselves are edited with the other cad tools.

Use it
- "Put the wheels on their own layer and colour it red", "hide the fixtures", "show only the housing", "select the four holes", "undo that", "look at it in 2D".
- After building a model: layer_create for each system, then view_fit.
- "show me the section at z = 40", "cut it through the middle of the hole", "look inside at x = 0": section_on with the axis and the position in mm. Everything above the plane (not inverted) is cut away, so the inside is seen from above; inverted true keeps the part above instead. Move the cut by calling section_on again with another position; section_off puts the whole model back. Use cad_describe_drawing first to know where the features are.

Do not use it
- To create or change geometry (cad_add_elements, cad_modify_entities, cad_transform_entities).

Parameters
- actions: 1 to 40 flat objects done in order, each {"action": <name>, ...fields}.
- action names: layer_create, layer_rename, layer_color, layer_show, layer_hide, layer_lock, layer_unlock, layer_delete, layer_activate (all need layer); view_3d, view_2d, view_fit; section_on (needs position; axis x|y|z default z, inverted optional), section_off; select, show, hide, isolate (need ids); select_none; undo, redo.
- layer: the layer's name (case does not matter; layer_create makes it if missing).
- newName: the new name for layer_rename.
- color: "#rrggbb" for layer_color (and for layer_create).
- moveTo: for layer_delete, the layer whose name receives the elements of the deleted one (default the active layer).
- ids: element ids for select, show, hide and isolate.
- axis, position, inverted: for section_on. axis is "x", "y" or "z" (default: the axis already set, z at first); position is the plane's coordinate on that axis in mm; inverted flips the side that is kept.

Result (JSON)
- ok and the actions, which the editor performs as it reads the result. ok false with problems naming each incomplete action; nothing is done then.
- An action on a layer that does not exist is skipped by the editor and does not stop the others.
