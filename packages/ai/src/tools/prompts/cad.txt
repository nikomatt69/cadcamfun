Read and inspect the open drawing. Every action is read-only.

Actions and Parameters (lengths mm; history and joint angles degrees)
- describe: counts, bounds, layers; no parameters. Start here.
- check: sizes, operands, duplicates and floating parts; no parameters.
- relations: firstId, secondId; bounds, placement and dependencies.
- grep: query, layerId?, parametricOnly?, includeParameters?, offset?, limit?; search properties and parameters with revisions.
- vision: focus?; capture the visible CAD viewport.
- inspect_elements: ids?, layerId?, offset?, limit?; full element properties, paged.
- inspect_layers: no parameters; layers and active layer.
- inspect_search: query, layerId?, limit?; matching text.
- inspect_property: elementId, path (property-name array), offset?, maxChars?; one property, paged.
- inspect_origins: ids?, layerId?, offset?, limit?; origins, bounds and distance from zero.
- drawing: elementId or history, options?; dimensioned PDF/SVG. Options include GDT, datums, balloons; see schema.
- parametric_validate: history; build and validate before storing.
- parametric_inspect: elementId; parameters and revision.
- parametric_test: elementId, cases [{name,parameters,expectedBodies?,minVolumeMm3?,maxVolumeMm3?,checks?}]; dimensional checks and variants.
- parametric_dfm: elementId or history, process (mill|turn|print), toolDiameter?, material?, minWall?, envelope? {x,y,z}.
- parametric_exact: elementId or history, includeStep?, name?; exact body or reason it is mesh-only.
- exact: ids?, machining?; exact validity, volume, bounds, faceNames, holes and CAM suitability.
- assembly: washers?; exact clashes, gaps, BOM, joints, missing fasteners.
- setups: ids?, fixture?, allowed?; setup orientations per solid.
- distance: firstId, secondId; smallest exact gap and closest points.
- shell: id, thickness, open? (face names), wallByFace? [{face,thickness}]; preview. Get names from exact.
- hole: id, hole|boss|fillet, diameter?|fill?|radius?, taper?; preview; indexes from exact.
- offset: id, distance; outward offset preview, rounded convex corners. Unsupported geometry returns a reason.
- motion: model {ground,joints,couplings?,contacts?}, sweep {joint,from,to,steps,quantity?}; scene part ids, zero-pose world origins/axes. closesLoop constraints solve passive joints. Reports closure, contact gaps and clearance violations per frame; no contact-force simulation.
- surface: operation patch|stitch|thicken, patches [{data:{degreeU,degreeV,knotsU,knotsV,points,weights?},trim?:{u0,u1,v0,v1}}], thickness?, direction? {x,y,z}, tolerance?, name?. points[u][v]=[x,y,z]. Rectangular isoparametric trim; stitch matching full boundaries. Curved thicken requires explicit axial direction. General curved normal offsets are refused. Open surfaces are not CAM solids.
- exchange: format step|iges|parasolid, ids?; exact file text. Parasolid is explicitly unsupported.
- parametric_fastener: size?, fit?, shaftDiameter?; thread, tap, clearance and counterbore.
- parametric_recipe: recipe, params?; standard-part history. Recipes: mounting_plate, flange, l_bracket, stepped_shaft, pipe_bend, duct_transition, enclosure.
- parametric_from_element: elementId, depth?; named dimensions from existing geometry.

Result (JSON)
ok, geometry findings or problems; paged inspection gives total/nextOffset. Element ids are edit ids; parameter revisions guard later updates.

Do not use it
To write use cad_edit; to machine use cam/cam_edit. Store checked shell, offset or surface with cad_edit. Consult fusion-360-modelling for history features and supported domains.
