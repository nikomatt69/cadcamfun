Read the open drawing. All actions are read-only.

Actions
- describe: the drawing: counts, bounds and layers. Start here.
- check: model checks (sizes, rotations, Boolean operands, duplicates, floating parts); fix findings.
- relations: bounds, placement, distances and parameter dependencies; equal names do not bind parameters.
- grep: search ids, names, layers and properties; parametric hits carry a revision.
- vision: the CAD viewport and scene evidence as an image.
- inspect_elements: full properties and bounds of elements, paged.
- inspect_layers: the workspace layers and the active one.
- inspect_search: elements whose text matches a query, paged.
- inspect_property: one property of one element by path, paged by characters.
- inspect_origins: where each element sits: origin and its meaning for the type, bounds, distance from the CAD zero, children.
- parametric_validate: rebuild a parametric history and report what it cannot build.
- parametric_inspect: history, parameters and report of one parametric part.
- drawing: technical sheet from an elementId or history; SVG with dimensions, callouts, warnings; view options in the schema.
- parametric_test: run parameter variants; report bodies, volumes and dimensional checks.
- parametric_dfm: manufacturability findings for a history or part.
- parametric_exact: exact B-rep per body (volume, area, centroid, throughHoles, faces, surfaces) or why mesh-only; STEP on request.
- exact: every solid on the exact kernel: validity, volume, bounds, holes, and whether CAM machines it by features or 3D surface.
- assembly: exact interference (clash volumes), bill of materials with mass, hole joints, fasteners still missing.
- parametric_fastener: thread, tap drill, clearance and counterbore of a metric size.
- parametric_recipe: part history from `recipe` (mounting_plate, flange, l_bracket, stepped_shaft, pipe_bend, duct_transition, enclosure) and `params`; cad_edit.parametric_recipe_create stores it.
- parametric_from_element: history with named parameters from a solid, flat shape or component; cad_edit.parametric_convert stores it.

Parameters (mm, radians; ids are read, never invented)
- describe, check, inspect_layers: none.
- relations: firstId, secondId - two different existing ids.
- grep: query (1-200 chars), layerId, parametricOnly, includeParameters, offset, limit (1-50).
- vision: focus - what to look at.
- inspect_elements: ids (max 100), layerId, offset (default 0), limit (max 100, default 10).
- inspect_search: query, layerId, limit (max 100, default 20).
- inspect_property: elementId, path (1-12 property names), offset (default 0), maxChars (default 10000, max 50000).
- inspect_origins: as inspect_elements (ids max 100, layerId, offset, limit).
- parametric_validate: history - the part's history object.
- parametric_inspect, parametric_test: elementId; test also takes cases (1-12): [{name, parameters, expectedBodies?, minVolumeMm3?, maxVolumeMm3?, checks?}]. checks (all must measure inside their limits): {kind, name} plus the kind's nominal and tolerance (schema).
- parametric_dfm, parametric_exact: one of elementId or history. exact: includeStep, name. dfm: process (mill|turn|print), toolDiameter, material (metal|cast|plastic), minWall, envelope {x,y,z}.
- exact: ids (max 40, default all), machining (default true). assembly: washers (default true).
- parametric_fastener: size (M3 ...), fit (fine|medium|coarse), shaftDiameter.
- parametric_from_element: elementId, depth (mm, only for a flat shape: its extrusion, default 10).

Result (JSON)
- ok; describe: elements, counts, bounds; inspect: page, total, nextOffset; origins: the CAD 0,0,0 then per element origin, convention, bounds, distanceFromZeroMm, gizmo, children; parametric: report with bodyCount, volumeMm3, problems. Element ids are the edit ids.

Do not use it
- To change something: cad_edit. To machine: cam and cam_edit.

After it
- Report ids, positions and bounds; check or verify claims.
