Read the open drawing. All actions are read-only.

Actions
- describe: the drawing: counts, bounds and layers. Start here.
- check: model checks (sizes, rotations, Boolean operands, duplicates, floating parts); fix findings after modelling.
- relations: bounds, placement, distances and parameter dependencies; equal names do not bind parameters.
- grep: search ids, names, layers and properties; includes each parametric hit's revision.
- vision: the CAD viewport plus scene evidence as an image.
- inspect_elements: full properties and bounds of elements, paged.
- inspect_layers: the workspace layers and the active one.
- inspect_search: elements whose text matches a query, paged.
- inspect_property: one property of one element by path, paged by characters.
- parametric_validate: rebuild a parametric history and report what it cannot build.
- parametric_inspect: history, parameters and report of one parametric part.
- drawing: technical sheet (SVG, dimensions, callouts, warnings) from exactly one elementId or history; options (size, projection, title block, views, iso, scale, section, detail, flatness) as in the schema. Local mm, approximate mesh edges, nothing stored.
- parametric_test: run parameter variants; report bodies and volumes.
- parametric_dfm: manufacturability findings for a history or an existing part.
- parametric_exact: exact B-rep per body (volume, area, centroid, throughHoles, faces, surfaces) or why mesh-only; STEP on request.
- exact: every solid on the exact kernel (STEP imports, Booleans, parts): validity, volume, bounds, holes, and whether CAM machines it by features or as a 3D surface job, with the reason.
- assembly: exact interference (clash volumes), bill of materials with mass, hole joints, fasteners still missing.
- parametric_fastener: thread, tap drill, clearance and counterbore of a metric size.
- parametric_recipe: standard part history; `recipe` is mounting_plate, flange, l_bracket, stepped_shaft, enclosure, pipe_bend or duct_transition. cad_edit.parametric_recipe_create stores it.
- parametric_from_element: history with named parameters from an existing solid, flat shape or component; cad_edit.parametric_convert stores it.

Parameters (mm, radians; ids are read, never invented)
- describe, check, inspect_layers: none.
- relations: firstId, secondId - two different existing ids.
- grep: query (1-200 chars), layerId, parametricOnly (default false), includeParameters (default true), offset (default 0), limit (1-50, default 20).
- vision: focus - what to look at.
- inspect_elements: ids (max 20), layerId, offset (default 0), limit (max 20, default 10).
- inspect_search: query, layerId, limit (max 50, default 20).
- inspect_property: elementId, path (1-12 property names), offset (default 0), maxChars (default 10000).
- parametric_validate: history - the part's history object.
- parametric_inspect, parametric_test: elementId; test also takes cases: [{name, parameters, expectedBodies?, minVolumeMm3?, maxVolumeMm3?}] (1-12).
- parametric_dfm, parametric_exact: exactly one of elementId or history. exact: includeStep, name. dfm: process (mill|turn|print), toolDiameter, material (metal|cast|plastic), minWall, envelope {x,y,z}.
- exact: ids (max 40, default all), machining (default true). assembly: washers (default true).
- parametric_fastener: size (M3 ...), fit (fine|medium|coarse), shaftDiameter.
- parametric_recipe: recipe (a name above), params (the recipe's design inputs).
- parametric_from_element: elementId, depth (mm, only for a flat shape: its extrusion, default 10).

Result (JSON)
- ok; describe: elements, counts, bounds; inspect: page, total, nextOffset; parametric: report with bodyCount, volumeMm3, problems. Element ids are the ids the edit actions take.

Do not use it
- To change something: cad_edit (add, modify, transform, group, delete, import, parametric writes).
- To machine: cam and cam_edit, not this tool.

After it
- Report ids, positions and bounds; check or verify claims.
