Automatically save a verified, reusable project fact after a successful setup or a user correction. Do not save a failed call, an unverified assumption or a transient progress log. Notes are scoped to this project and overwrite the same key.

Save a short note that you will see again in later conversations: a preference, a fact about the part, the stock or the machine.

Use it
- When the user says "always", "remember", gives units, stock size, machine or material they will reuse.

Do not use it
- For things visible in the drawing, or for secrets: never store passwords, keys or personal data.

Parameters
- key: letters, digits, dot, underscore, hyphen, 1 to 80 characters (e.g. "stock.size"). The same key replaces the old note.
- value: the note, 1 to 2000 characters, plain text.

Result (JSON): {ok, key}.
