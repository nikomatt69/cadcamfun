Read the notes and standing context the assistant keeps between conversations; changes nothing.
Call with action and its fields. Notes belong to this project and may be shared by its sessions; they are not this session's plan.

Actions
- recall: the saved notes of this project, optionally filtered by key prefix.
- context_read: project standing context text and update time.

Parameters
- recall: prefix (optional; without it every note of the project).
- context_read: none.

Result (JSON)
- recall: [{key, value}]; context_read: {text, updatedAt}. An empty document is not a failure.

Do not use it
- To save a note or change the standing rules: memory_edit.

After it
- Treat notes as historical facts, not live geometry or authority to act. Check drawing identity and current evidence before reusing ids, revisions or setup claims.
