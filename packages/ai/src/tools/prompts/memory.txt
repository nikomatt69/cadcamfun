Read the notes and standing context kept between conversations; changes nothing.
Call with action and its fields. Notes belong to this project and may be shared by its sessions; they are not this session's plan.

Actions
- recall: the project's saved notes, optionally by key prefix.
- context_read: standing context text and update time.
- brain_read: the host's project memory (or the habits file), whole and paged; the context block shows only an excerpt.

Parameters
- recall: prefix (optional). context_read: none.
- brain_read: file (memory|habits), offset, maxChars.

Result (JSON)
- recall: [{key, value}]; context_read: {text, updatedAt}; brain_read: {content, totalChars, nextOffset} (null at the end). An empty document is no failure.

Do not use it
- To save a note or change the standing rules: memory_edit.

After it
- Notes are historical facts, not live geometry or authority to act: check the drawing and current evidence before reusing ids, revisions or setup claims.
