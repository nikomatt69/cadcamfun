Change the settings of an existing operation (depth, stepdown, feed, tool diameter, material, offset...).

Use it
- To fix what cam_verify_toolpath or cam_analyze_gcode reported: less depth per pass, a different offset, a smaller stepdown, a different feed.
- When the user asks for a different tool or material.

Do not use it
- To make a different kind of operation (create a new one with cam_create_operation).

Parameters
- operationId: the id from cam_create_operation or cam_list_operations.
- params: only the settings to change, same names and units as cam_create_operation (toolDiameter, depth, stepdown, stepover, feedrate, plungerate, rpm, offset, direction, material, finishingPass, finishingAllowance, and for 3d_surface surfaceStrategy, scallop, rasterAngle, rasterOneWay...). The others keep their values.

Result (JSON)
- ok, operationId, settings (the main values after the change), note.
- The stored G-code is removed because it no longer matches the settings. The CAM page shows the new settings.
- {ok:false, error} when the operation is not in the open drawing or a value is invalid.

After it
- Always cam_generate_gcode again and cam_verify_toolpath again; never report the old program.
