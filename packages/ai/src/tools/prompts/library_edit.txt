Create, replace or remove rows of the user's libraries, and set a project's defaults.

Actions
- upsert_material: create a material row, or replace an existing one when id names a row you may write.
- upsert_tool: create a cutter row, or replace one.
- upsert_machine_config: create a machine configuration, or replace one.
- set_default: the project's default material, tool and machine, used to seed new operations.
- delete: remove one row of the user's libraries. Destructive: the host asks before the tool runs.

Parameters
- upsert_material: id (omit to create), name, description, properties ({name: number|string|boolean}), isPublic.
- upsert_tool: id, name, type, diameter (mm), material, numberOfFlutes, maxRPM, coolantType, cuttingLength, totalLength, shankDiameter, notes, isPublic.
- upsert_machine_config: id, name, kind (mill|lathe|3Dprinter), kinematics ({axis: {min, max}}), postProcessor, workOffsets, probing, maxRPM, maxFeed, isPublic.
- set_default: materialId, toolId, machineConfigId (any subset; the open project is the one that changes).
- delete: kind (material|tool|machine_config), id.

Result (JSON)
- ok, id, created (true when a row was created, false when an existing one was replaced); the store's answer, not the intention. delete also returns what still refers to the row.

Do not use it
- To read what exists: library is read-only and free of side effects.
- Never invent a material, a cutter or a machine: only write rows from real user- or manufacturer-supplied values, and only when the user asked.

On refusal
- An id that does not exist is refused: no replacement is created in its place.
- A row you may not write is refused; the acting user owns that decision.
