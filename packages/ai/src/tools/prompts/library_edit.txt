Create, replace or delete the user's materials, cutters, machines, costs and project defaults.
Call with action and its fields. Read an existing row before replacing it; preserve known fields.

Actions
- upsert_material: create a material row, or replace an existing one when id names a row you may write.
- upsert_tool: create a cutter row, or replace one.
- upsert_machine_config: create a machine configuration, or replace one.
- upsert_library_item: create or replace a generic item (template, setup sheet, fixture).
- set_cost: create or update a price: material cost, cutter wear, operation rates.
- set_default: the project's default material, tool and machine, used to seed new operations.
- delete: remove one row of the user's libraries. Destructive: send confirm true only after the user asked for it.

Parameters
- upsert_material: id (omit to create), name, description, properties ({name: number|string|boolean}), isPublic.
- upsert_tool: id, name, type, diameter (mm), material, numberOfFlutes, maxRPM, coolantType, cuttingLength, totalLength, shankDiameter, cornerRadius (mm, 0 is sharp), tipAngle (degrees), threadPitch (mm), holderDiameter, holderLength, stickout (mm), notes, isPublic.
- upsert_machine_config: id, name, kind (mill|lathe|3Dprinter), description, controller (real control name), post (generic|fanuc|grbl|linuxcnc|haas|siemens|heidenhain|okuma|mazak), axes, axisTable, spindle, feed, rigidity, workVolume, travel, table, rotary, turning, workOffsets, probing, toolSetter, workOffsetTable, rotaryCalibration, toolChanger, coolant, accuracy, reference, kinematics, postProcessor, maxRPM, maxFeed, isPublic. Use the loaded schema for nested configuration fields; preserve measured limits and manufacturer reference.
- upsert_library_item: id, name, category, type, data ({...}), description, properties, tags, isPublic.
- set_cost: kind (material|tool_wear|operation), id (omit to create). material: materialId, costPerUnit, wasteFactor, minimumCharge. tool_wear: toolId, wearRatePerMeter, replacementCost, replacementThreshold. operation: name, machineHourlyRate, operatorHourlyRate, setupTime (min). currencyCode.
- set_default: materialId, toolId, machineConfigId (any subset; the open project is the one that changes).
- delete: kind (material|tool|machine_config|library_item), id, confirm (true).

Supply required fields from real data; omit unknown optional values instead of inventing them. Keep units (mm, rpm, mm/min) and dimensions consistent. cornerRadius, tipAngle, threadPitch and holder* draw the tool's model: include only supported values for that cutter.

Result (JSON)
- ok, id, created (true: created, false: an existing row replaced). delete also returns what still refers to the row.

Do not use it
- To read what exists: library is read-only.
- Never invent a material, a cutter or a machine: only write rows from real user- or manufacturer-supplied values, and only when the user asked.

On refusal
- An id that does not exist is refused: no replacement is created in its place.
- A row you may not write is refused; the acting user owns that decision.
