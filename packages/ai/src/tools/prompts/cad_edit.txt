Edit the open drawing.

Actions and Parameters (mm; rotation/history angles degrees)
- add: elements (1..40) [{type,...fields}]; editor solids, curves, booleans and components. Valid elements are stored; invalid ones appear under skipped. Catalogue: cad-3d-modeling.
- add_entities: entities (1..500) of line/circle/arc/polyline/rectangle; flat 2D sketches only when requested. Each accepts layer, name, color.
- modify: changes:[{id,changes:{color:"#808080"}}]; edit fields.
- transform: ids, dx?, dy?, dz?, rotateAxis?, rotateDegrees?, scale?, about? {x,y,z}, copies? (0=move, up to 100).
- group: ids, name?, ungroup?, layer?; assemble or open a component.
- delete: ids, confirm:true only when the user requested deletion. Destructive; host permission still applies.
- editor: actions:[{action:"layer_color",layer:"Metal",color:"#808080"}] (1..40): layer_create/rename/color/show/hide/lock/unlock/delete/activate, view_3d/2d/fit, section_on/off, select/select_none, show/hide/isolate, undo/redo; fields layer, newName, color, moveTo, ids, axis, position, inverted.
- import: attachment (preferred) or content, format? dxf|svg|step|iges|parasolid|mesh, depth? (required dxf/svg), up? (STEP), scale?, gap?, tolerance?, name?, color?, layer?. IGES stores exact solids; incomplete imports store nothing. Parasolid x_t text/x_b binary are unsupported. STEP/IGES imports recover geometry, not history.
- export: format stl|stl_ascii|obj|3mf|step|iges, ids? (default all) or history, name?, unit?, tolerance?. Stores a file; answer: file {name,key,bytes,sha256}.
- fasten: washers?. Inserts the screws, washers, nuts cad assembly lists missing.
- parametric_create: history, name, x?, y?, z?, layer?. Store a validated history; sketches use shapes or point/line/arc entities and constraints. See fusion-360-modelling.
- parametric_update: elementId, parameters, expectedRevision from the last inspection; sets existing parameters only.
- parametric_edit: elementId, expectedRevision, edits (1..40, atomic) of op: set_parameter name,value | rename_parameter from,to | remove_parameter name | set_dimension feature,path,value | replace_feature feature | insert_feature feature,after?|atStart? | remove_feature id,cascade? | rename_feature id,name? | group_features group,name,ids | ungroup_features group. Values: numbers or parameter expressions; paths from parametric_inspect.
- parametric_timeline: elementId, expectedRevision, suppress? release? (feature ids), rollback? (last built feature) | rollForward?, move? {feature,to}. Nothing is deleted; refused moves say why.
- parametric_recipe_create: recipe, params?, name?, x?, y?, z?, layer?. Build and store a standard part.
- parametric_convert: elementId, depth? (flat shapes), name?. Store a parametric twin preserving shape, placement and properties; original remains.
- shell: id, thickness, open? (face names), wallByFace? [{face,thickness}]. Store a checked exact copy. Preview cad.shell; names cad.exact.
- title_block_set: titleBlock {title?, number?, revision?, status?, ...}; only given fields change.
- hole: id, hole|boss|fillet|nurbs, diameter?|fill?|radius?|distance?|angle?, taper?, mode? (move|offset|draft), direction?, neutral?, pull?, tolerance?. Stores a checked copy. Preview cad.hole.
- offset: id, distance (outward). Store a checked exact copy; source remains. Preview cad.offset.
- surface: operation patch|stitch|thicken, patches (data, trim?), thickness?, direction?, tolerance?, name?; as cad.surface, with the same thicken limits. Open surface bodies are excluded from solid analysis and CAM.

History additions
Fillet radiusEnd varies the radius along a straight edge (chamfers refuse it). Sheet flanges [{end,length,angle,relief?{width,depth}}] extend exposed full-width edges with the sheet bendRadius; flatPatterns report the blank. Adjacent-edge corners are unsupported. Hole takes thread {designation,depth,fit?}, tolerance {upper,lower}, fit (H7) for the drawing; thread takes designation.

Result (JSON)
ok, ids, elements, projectId, drawingId; parametric writes include revision/report. ok:false explains refusal; nothing is stored on a failed exact construction.

Do not use it
For inspection use cad. Move or modify existing geometry instead of deleting and rebuilding it.

After it
Check with cad.check/cad.exact; for assemblies also cad.assembly and cad.distance before declaring completion.
