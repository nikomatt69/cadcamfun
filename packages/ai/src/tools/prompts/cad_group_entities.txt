Gather existing elements into one component (a named part the user can select and move as one), or open a component back into its parts.

Use it
- "Make the wheel a component", "group the legs", "ungroup the bracket". When you create things yourself, prefer the component field of cad_add_elements.

Do not use it
- To create the parts: cad_add_elements. To move them: cad_transform_entities.
- To group a Boolean or an element a Boolean uses as an operand: it stays where it is.

Parameters
- ids: the elements to gather (1 to 200), or with ungroup the components to open.
- name: the component's name when gathering (default "Component").
- ungroup: true opens the components in ids into their parts at their own places. A component that is turned or scaled cannot be opened: say so.
- layer: the layer of the new component (default the layer of the first element).

Result (JSON)
- ok, removed (ids that left the drawing), ids (the new component, or the freed parts), elements (what was added). The editor shows it at once.
- ok false with an error when an id is unknown, a Boolean is involved, or the component cannot be opened.
