Search the user's tool library.

Use it
- When the user names a cutter, or before cam_create_operation to pick a real tool and its diameter.

Parameters
- query: words from the name or type ("6 mm end mill").

Result (JSON): up to 10 of {id, name, diameter (mm), type}, public library entries included.
- Use diameter and type as toolDiameter and toolType of the operation. The library does not give flute length or holder: ask, or leave those unmodelled in cam_verify_toolpath and say so.
- No match: say so and state the tool you assumed.
