Search the user's tool library.

Use it
- When the user names a cutter, or before cam_create_operation to pick a real tool and its diameter.

Parameters
- query: words from the name or type ("6 mm end mill").

Result (JSON): up to 10 of {id, name, diameter (mm), type, material, numberOfFlutes, maxRPM, coolantType, cuttingLength, totalLength, shankDiameter, notes}, public library entries included.
- Use diameter and type as toolDiameter and toolType of the operation. Use cuttingLength and shankDiameter when present; stickout and holder dimensions remain unknown unless given. Missing lengths must be left unmodelled in cam_verify_toolpath and reported.
- No match: say so and state the tool you assumed.
