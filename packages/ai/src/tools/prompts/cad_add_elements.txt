Build geometry in the editor the user has open, in the editor's own element format. This is THE way to create objects: parts, shapes, assemblies. Everything is built in 3D unless the user explicitly asks for a flat sketch.

Use it
- Any object the user names: a bracket, a car, a bottle, a gear, a house. Compose it from as many elements as it takes to look right.
- Holes, pockets and cut-outs: a solid plus a second solid and a boolean-subtract.
- Curves and profiles: spline, bezier, nurbs, extrusion, revolution, sweep, loft.
- Standard parts: gear, spring, bolt, screw, nut, washer.

Do not use it
- For a flat 2D sketch the user asked for ("draw a circle", a profile to machine): cad_add_entities.
- To change an existing element: cad_modify_entities with its id.

Parameters
- elements: 1 to 40 objects per call (a bigger model is several calls, each part of it logical: body, then wheels, then details; a very long call is cut off by the model's own output limit and fails), each {"type": <one of the types below>, ...fields}. Fields you leave out take the defaults of the editor's tool panel; fields you give must have the right JSON type (number, string, array).
- Common to every type: tolerance, x, y, z (position in mm; the centre of a solid, the origin of a profile), name, color ("#rrggbb"), rotation {x,y,z} in DEGREES (the editor's own unit; arc and revolution angles stay in radians), wireframe, layer (a layer name; it is created if it does not exist).
- Each element is judged on its own: the valid ones are added, the invalid ones are listed under "skipped" ({index, error}) and are NOT in the drawing. Resend only those, corrected; never resend the ones that were added. A boolean whose operand was skipped is skipped too. If every element is invalid, "ok" is false and "problems" lists them all.
- operands (booleans): ids of existing elements, or the index (0-based) of an earlier element of the SAME call.

Precision (microns)
- Numbers keep every decimal you give: 0.001 mm is 1 micron. Never round a dimension that has a tolerance; give the nominal or the middle of the limits (a 25 H7 hole is 25.0105, not 25).
- Round shapes are drawn as meshes. With no setting they use 32 segments, which for a radius of 50 mm deviates by 0.24 mm. Give "tolerance" (the allowed deviation in mm, e.g. 0.001) on circle, ellipse, cylinder, cone, sphere, hemisphere, ellipsoid, capsule, torus and revolution and the segment counts are computed for you; "segments" sets them by hand (3 to 2048).
- If the finest mesh the editor draws cannot reach the tolerance, the result carries "warnings" with the deviation actually achieved. Report it.
- The editor shows the model; the toolpath and the verification work from the numbers and a tolerance of their own (see cam_create_operation and cam_verify_toolpath).

Types and their fields
{{elements}}

Conventions
- Millimetres and radians. cylinder, cone and capsule stand along Z; revolution turns its profile about its axis (profile x = radius, y = height along the axis).
- rectangle, circle, polygon, ellipse are flat on the XY plane at height z.
- Place parts relative to each other with x, y, z: a wheel is a cylinder whose centre is where the wheel is.

Result (JSON)
- ok, ids (one per element, in order), elements (what was stored, with defaults filled), projectId, drawingId.
- Elements appear in the user's editor immediately and the view switches to 3D.

Examples
- A block with a hole: [{"type":"cube","width":60,"height":40,"depth":20},{"type":"cylinder","radius":6,"height":30},{"type":"boolean-subtract","operands":[0,1]}]
- A bottle: [{"type":"revolution","name":"Bottle","profile":[{"x":0,"y":0},{"x":30,"y":0},{"x":30,"y":150},{"x":10,"y":200},{"x":10,"y":260}]}]

After it
