Inspect or set the real raw stock for the current drawing and machining operations. Stock is separate from finished part geometry. Do not estimate removed material by subtracting unrelated element bounding boxes.

One stock, two faces: the drawing's stored stock is what CAM reads (generation, verification, invalidation) and what this tool reports back, and the same stock is written as a `workpiece` element, which is the raw piece the CAD scene draws. Setting it therefore sets both the CAD stock and the CAM stock: the raw piece is visible in the editor, survives reopening the project and travels with the project's history.

Parameters
- action: inspect | set.
- stock: set requires width (X), height (Y), depth (Z thickness), all positive mm; x and y are stock centre in CAD coordinates (default 0), topZ is the top face (default 0). Stock occupies Z from topZ-depth to topZ.
- radius: optional cylindrical-stock hint (default 0); allowance: nominal allowance mm, default 1; material: material name; elementId: optional existing element used as a reference.
- Do not use it to define part geometry: the workpiece element is the raw piece, never a part to machine, and the generator ignores it. Point elementId at a real part element only when that element *is* the raw piece; then nothing is added to the scene and the stock keeps that element as its source.

Result
inspect returns configured stock, origin conventions and volume in mm³, or an explicit missing-stock result. It also returns the workpiece element (id, name, width, height, depth, x, y, z) and workpieceMatchesStock, which is false when the CAD scene and the CAM stock disagree: set the stock again to bring them back together. set writes the drawing's stock, creates or updates the workpiece element (its centre is x, y, topZ-depth/2, so its top face is topZ), invalidates G-code/verification of affected operations and mirrors dimensions and placement into the UI. Re-generate and run cam_verify_toolpath before claiming a program is valid. A radius marks a cylindrical stock while the CAD scene draws the workpiece element as a box; the verifier uses a box heightfield in both cases.

Missing-stock recovery
A missing stock result from inspect is a prerequisite, not a broken tool. Read the actual part extents, material and setup. If the user authorised choosing the setup, use action set with explicit dimensions, placement and stated allowance, then inspect again. Otherwise use question to obtain the missing stock dimensions. Never repeat inspect unchanged or invent quantitative removal from absent stock.
