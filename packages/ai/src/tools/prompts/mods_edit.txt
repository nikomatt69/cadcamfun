Write, enable, disable or remove a mod: a standing rule that survives a restart.
Call with action and its fields. A mod runs in the host and affects the whole application, not just this drawing/session; inspect existing source/state first.

Authoring (the only shape the store accepts)
- Dependency-free ESM: no import/require. Export register(on, options); register on(event, matcher?, hook). Matchers accept values, arrays or RegExp.
- A hook is async ($, e, next), with frozen e. next(e) observes, next({...e, field}) rewrites, {deny:"reason"} refuses; awaiting next(e) allows result wrapping. Throwing/slow hooks are skipped; use the registration's .catch(...) for fail-closed rules.
- Events include tool.call (tool,input), tool.check (patterns,rule), prompt.submit (text,context), session.start/end/compact, turn.start/step/complete, skill.prompt, command.run/describe, spawn/offer and ui.*. Choose the narrow event; do not alter unrelated calls.
- $ API: ui, tool.register (dispose removes it), command.register, prompt.submit/fill, turn.abort, session, model.complete/classify, mcp.call, settings.read, env.get/set, fs, process.run/spawn, http.fetch, store (machine-wide, 4 MiB), state, clock. No invented globals, secrets in storage, or project payloads in logs/external calls.

Actions
- save: create/replace source; new mods default disabled, enable true arms, false stops, absent preserves state. Ask before replacing another author's source.
- set_enabled: arm/stop. Every call requires native human approval.
- remove: delete source and record permanently.

Parameters
- save: id (lower-case file name, up to 40 characters, e.g. `confirm_deletes`), name? (up to 60), description (what it hooks and why, up to 200), source (up to 20000 characters), enable?.
- set_enabled: id, enabled. remove: id.

Result (JSON)
- save/set_enabled: ok, id, enabled, events[], reloaded. remove: ok, id, removed:true. Read refusal problems before correcting source.
- Refused loading disables the mod again. Reload/inspection failures may retain stored state with a note: reread before assuming hooks are active.

Rules
- Change/enable/remove only when requested or agreed. Write readable single-purpose source; the user can review it in Extensions. Changes apply from the next turn.

Do not use it
- To read, list or review mods: `mods`.
- To change the drawing, the CAM program or project memory: `cad_edit`, `cam_edit`, `memory_edit`.
