Hand a job to a subagent that has only the tools that job needs. The subagent does not see this conversation. The job shows in the chat as a task card that follows it to its report.

Actions
- start: give one bounded job to a specialist (researcher, editor, modeler, machinist, reviewer, planner, diagnostician, verifier or optimizer).
- list: the tasks started from this conversation, with their status.
- read: the full findings of one task.
- cancel: stop a task that is no longer needed.

Parameters
- start: description (one line), prompt (the whole job: the entity ids, values, constraints and what to report), agent (or subagent_type), background (default true: the call returns at once and the completion wakes this conversation; pass false only when the next step needs the report before it can start).
- list: none.
- read, cancel: taskId (the id the call returned).

Result (JSON)
- start: the task (its report arrives on the completion wake); with background false the finished task. read: the task with its status and findings. cancel: the cancelled task.

Do not use it
- To do the job yourself: delegate only separable work the specialist has tools for.
- Verify what an editing specialist reports (cad.describe, cad.check) before telling the user it is done.

Rules
- Always background: start returns at once; never block waiting on a subagent. Start independent jobs together so they run concurrently, and the completion wakes this conversation with each report.
- Give real ids, units, constraints and the report you expect; a specialist that has to guess wastes the turn.
- Editing subagents run one at a time per project; the scheduler queues them.
