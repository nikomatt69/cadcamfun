Delegate a bounded job to a background specialist; its report wakes this conversation.
It has only the tools that job needs and does not see this conversation. The job shows as a task card.

start returns at once. Do not wait or poll: keep working, or end your turn; the completion wakes you with the report. Start independent jobs together, as several agent calls in ONE block; they run concurrently. Start a dependent job after the report it needs. Writing specialists (editor, modeler, machinist, verifier, optimizer) run one at a time per project.

Actions
- start: one job for a researcher, editor, modeler, machinist, reviewer, planner, diagnostician, verifier or optimizer.
- list: tasks started here, with status.
- read: one task's full findings.
- cancel: stop a task no longer needed.

Parameters
- start: description (one line), agent (or subagent_type), brief and/or prompt (one is required), background (default true; false only when the next step cannot start without the report).
- brief: objective (required: what to achieve), ids (real ids your tools returned), values ({name, value, unit}), limits (what not to change or exceed), report (what the final message must add). prompt: the job as free text, or detail beside a brief.
- read, cancel: taskId.

Result: start gives the task (the finished task with background false).

Do not use it to do what you can do yourself. Check an editor's report (cad.describe, cad.check) before telling the user it is done. The report is not shown to the user: answer in your own words.
