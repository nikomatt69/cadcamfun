Delegate a bounded job to a background specialist; its report wakes this conversation.
Call with action and its fields. A specialist receives your brief, not this conversation; include the target, constraints and evidence it needs.

start returns at once by default; completion wakes this conversation. Continue independent work without polling. Do not claim completion while required reports are pending. Start independent jobs together; consume prerequisite reports before dependent work. Writing specialists (editor, modeler, machinist, verifier, optimizer) run one at a time per project; do not edit their target concurrently.

Actions
- start: one job for a researcher, editor, modeler, machinist, reviewer, planner, diagnostician, verifier or optimizer.
- list: tasks started here, with status and report size (read gives the report).
- read: one task's full findings.
- cancel: stop a task no longer needed.

Parameters
- start: description (one line), agent (or subagent_type), brief and/or prompt (one is required), background (default true; false only when the next step cannot start without the report).
- brief: objective (required), ids (real returned ids), values ({name,value,unit}), limits (constraints), report (string or string list, e.g. ["changed ids", "checks and limits"]). prompt: free-text job or details beside brief.
- read, cancel: taskId.

Result: start gives the admitted task (the terminal task with background false). Read status and errors: acceptance is not successful execution. list/read/cancel address this session's tasks only.

Do not use it for trivial work or to bypass permissions. Check claimed edits against current geometry and evidence before accepting a report. The report is not shown to the user: answer in your own words.
