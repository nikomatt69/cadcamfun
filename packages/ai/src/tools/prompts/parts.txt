Save drawing elements as a reusable component, insert a saved component, or delete it.
Call with action and its fields. Drawing ids select source elements; componentId identifies a saved part.

Actions
- save: save existing elements as a named project component, children relative to its origin, with library metadata.
- insert: place a saved component, optionally transformed; returns new drawing ids.
- delete: remove saved component, not its drawing instances. confirm true requires requested deletion; host approval still applies.

Parameters (mm, degrees)
- save: ids (the elements to gather), name, description, type, isPublic.
- insert: componentId, transform {move {x,y,z}, rotate {axis, degrees, about}, scale {factor, about}} - all parts optional.
- delete: componentId, confirm (true).

Result (JSON)
- ok; save returns componentId/child count, insert ids/elements, delete removed id. ok:false explains missing ids, empty parts or denied writes.

Do not use it
- To look up a component: library.lookup_component.
- To move an instance: cad_edit.transform.

After it
- Verify returned ids and cad.check after insertion. A saved component is not an inserted instance; retry only after checking what the prior call stored.
