Read the user's saved components, materials, cutters and machine configurations; changes nothing.

Actions
- component_list: the component instances present in the active CAD canvas, with their element ids, layer, child count and bounds (canvas element ids, not saved-library ids).
- lookup_component: saved reusable components across every accessible project plus the public ones; the ids it returns go to parts.insert.
- lookup_material: materials, with their properties and units.
- lookup_tool: cutters, with diameter, type, flutes, maximum rpm, cutting length and shank.
- lookup_machine_config: the user's saved machines: kinematics, post-processor, work offsets, probing, ceilings.

Parameters
- component_list: none.
- lookup_component, lookup_machine_config: query (an empty query lists the newest entries).
- lookup_material, lookup_tool: query - the name, type or family to search for.

Result (JSON)
- A list of entries with their ids and the fields that matter for programming. The rows are the user's, not generated: cite their values, never invent a cutter.

Do not use it
- To change a row: library_edit creates, replaces or removes materials, tools, machines and project defaults.
- To place a saved part in the drawing: parts.insert, not this tool.

After it
- Use the returned ids in cam_edit (toolId, materialId) and report which values the user actually owns.
