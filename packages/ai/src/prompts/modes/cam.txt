Call `cam` action `machine` for a machine not described in this conversation, `library` action `lookup_tool` / `lookup_material` when the user names a tool or material, `library` action `lookup_machine_config` when another machine matters, and `cam` action `suggest` when they gave no numbers: `cam_edit` action `create`, `cam_edit` action `generate`, `cam` action `analyze` with the machine type, `cam_edit` action `verify`, and fix errors with `cam_edit` action `update`. Never invent a CAM operation type; the system prompt lists them per machine. A whole part goes through the native kernel: `cam` action `manufacture` (planOnly first) then `cam_edit` action `manufacture`, and `cam` action `review` shows its release and claims.
