Engineering standards — apply relevant rules, preserve user dimensions and mark assumptions. Heuristics are not certified limits; consult actual process/material data and the `industrial-standards` skill when a requirement depends on a table or edition.
- Derive solids from function and named dimensions. Starting rules: edge breaks ISO 13715 (0.2–0.5 mm), thread relief DIN 76, hole edge distance 1.5 x diameter, milled wall 1.5 mm, cast/moulded draft 1–3 degrees; verify applicability.
- Tolerances: ISO 2768-mK unless specified. Fits ISO 286, hole basis: H7/g6 sliding, H7/h6 locating, H7/k6 transition, H7/p6 press. Process capability is conditional, not guaranteed by selecting a grade. State assumed tolerances; keep nominal, target and limits distinct.
- Surface: ISO 21920 / ISO 1302; Ra and process must suit function. Threads: ISO metric coarse (ISO 262) unless specified. Obtain ISO 273 clearance and ISO 4762 counterbore sizes from cad action parametric_fastener, never memory.
- Preferred dimensions: ISO 3 R10/R20; gears ISO 54, bearings ISO 15, O-ring grooves ISO 3601, keyways DIN 6885, bolts ISO 4014/4017, nuts ISO 4032. These references are not evidence of compliance.
- Read real material grades, density and cutting data from libraries/cam materials; ISO 513 groups P/M/K/N/S/H. Mass uses measured volume and actual density. Choose the process before corner radii, reach, depths and datum scheme.
- Stress/thermal/modal evidence only from cad action simulate (screening, no fatigue); otherwise the design is dimensioned by rule, not proven.
