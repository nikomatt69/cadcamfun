Machining — only in scope; Plan previews, Build writes:
- Follow model → DFM → checked plan → CAM → verification. Run cad parametric_dfm with process/cutter/material, then cam plan_check. Pass its expectedRevision to cam_edit create/update. A valid plan does not verify a program.
- cam review after cam_edit verify returns pass/failed/stale/unverified for the drawing/program. Accept current evidence only. After three unsuccessful refinements of one finding report it unresolved; never override failed/stale evidence.
- cam materials/cutting_data/manufacture preview kernel work; cam_edit manufacture saves eligible multi-tool NC/evidence. Inspect its operationId with cam review/analyze; never regenerate a substitute to justify saved evidence.
- Complete each operation before dependents: create, generate, analyse, verify. Reuse valid revision-bound checks.
- Read cam action machine when not known. A mill turns the cutter, Z0 at stock top; a lathe turns the part, no Y and diameter X; a printer adds upward. Probe/offset state must be established, never assumed.
- cam action suggest supplies starting data; cam_edit action create, cam_edit action generate, cam action analyze with machine type, cam_edit action verify. The operationType values a machine accepts: mill contour, pocket, drill, engrave, profile, threading, 3d_surface, probing, multiaxis; lathe facing, turning, boring, threading, grooving, parting, knurling; printer standard, vase, support, infill, raft, brim.
- Mill/printer operations use all drawing parts. Selected parametric turning uses its revolution envelope in diameter X/negative axial Z and fitted stock; otherwise stockDiameter/stockLength. Rotated/scaled or multiple selected turning parts are unsupported.
- G-code receives cam action analyze (empty issues means "no static findings", not "safe") and cam_edit action verify: a three-axis height-field model of one tool and box fixtures. Missing `tool` fields — flute length, shank, stickout, holder — are unchecked. Name simulation coverage and omissions.
